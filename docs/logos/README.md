# MTSYA — Logos (read before using either mark)

MTSYA runs **two coexisting brand directions** and each has its **own** logo. They are
never mixed. See [../design-language/two-directions.md](../design-language/two-directions.md).

## 1. Streetwear mark — "the Scale" (four-scale fish-scale emblem)

- Files: [`streetwear-scale-logo.png`](streetwear-scale-logo.png) · [`streetwear-scale-logo.svg`](streetwear-scale-logo.svg)
- Canonical source in repo: `research/streetwear-decode/scale-logo.png` / `.svg`
- **Geometry (non-negotiable):** EXACTLY four scales in a 1-2-1 diamond — one on top,
  two in the middle row, one single scale coming to a point at the bottom. Each scale is
  a **rounded scallop** fish-scale shape, NOT a sharp geometric diamond/rhombus.
- **Rendering:** small, thin **outline stitch only**, tone-on-tone, never a bright printed
  graphic. On dark cloth, stitch it **one shade lighter** so it stays legible.
- **Placement lesson:** LEFT CHEST on tops is the proven position. Centre-chest reliably
  inflates it to 6+ scales — avoid. On bottoms: left pocket / low left thigh.
- Used on: all DELUGE 01 streetwear (tees, tanks, hoodies, bottoms). This is the logo
  passed as the reference image to `scripts/generate-design.mjs`.

## 2. Main brand mark — the Matsya (Madhubani/Mithila fish)

- Files: [`main-matsya-fish-logo.png`](main-matsya-fish-logo.png) · [`main-matsya-lockup.png`](main-matsya-lockup.png)
- Canonical source in repo: `design-system/assets/logos/mtsya-fish.png`,
  `design-system/brand-assets/fish.png`, `public/assets/logos/mtsya-fish.png`
- Used on: the **quiet-luxury** direction — the website / e-commerce surfaces and the
  `design-system/`. Wordmark is lowercase `mtsya`.

## Hard rule
Never use the Madhubani/Matsya fish on streetwear garment assets, and never use the
four-scale Scale on quiet-luxury surfaces. They are deliberately separate systems.
