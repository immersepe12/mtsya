# DELUGE 01 — First Drop (curated finals)

The finalized first drop. Each garment has its final flat-lay and/or on-model shot here.
These are the **curated deliverables**; the raw iteration renders and draft shoots are kept
local (git-ignored) and are reproducible from their `prompt.txt` files.

## Contents
| Folder | What | Count |
|--------|------|-------|
| [`model-images/`](model-images/) | Tees, on-model (Depth, Net, Ripple, Abyss, Current, Rekha) | 6 |
| [`tank-images/`](tank-images/) | Tanks, on-model (Jamun, Dhoop, Kajal, Mitti, Bhanwar, Kagaz, Namak) | 7 |
| [`pant-images/`](pant-images/) | Bottoms, flat-lay + on-model (Bel, Gaad, Reta) | 3 |

Each subfolder has its own README with the per-piece table, models, source shoots and any
corrections log.

## The drop at a glance
- **Tees (6):** Depth · Net · Ripple · Abyss · Current · Rekha — material-led, tonal, wash
  and knit/rib structure as story. Shot on Arjun / Karan / Rehan on one cohesive cool-grey
  high-key studio (benchmarked to Current-on-Karan), oversized drop-shoulder fit.
- **Tanks (7):** Jamun · Dhoop · Kajal · Mitti · Bhanwar · Kagaz · Namak — broad straight
  athlete muscle-tank fit, calm one-texture wash, left-chest Scale. Warm-cream studio.
- **Bottoms (3):** Bel · Gaad · Reta — baggy wide-leg, open hem, ~500-550 GSM plush fleece,
  single-shade stone-wash, hull-plank seams / kinari braid. Full-body cool-grey studio.
