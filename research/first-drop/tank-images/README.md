# DELUGE 01 — First Drop Tanks (on-model)

The seven finalized tank tops, each on-model. Cohesive as one batch on the same
warm-cream high-key studio, the canonical oversized capped-shoulder boxy muscle-tank
fit (per the tank design language: broad straight athlete cut, calm one-texture rule,
wash-led, left-chest four-scale mark), front-on framing, baggy washed trousers below.

Kajal was re-shot broader (wider capped-shoulder shelf, deeper open armhole) to match
Jamun's fit — the earlier frame read too narrow/closed.
